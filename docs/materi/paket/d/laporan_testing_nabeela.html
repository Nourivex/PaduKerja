Endpoint / API Akun & Keahlian (Auth & Profile Service)
  • POST /api/auth/login (Otentikasi & Penerbitan Token JWT)
  • PUT /api/profile/skills (Simpan & Pembaruan Matriks Keahlian)
  • GET /api/auth/me (Verifikasi Profil Terotentikasi)
Request 1 Method: POST | URL: http://127.0.0.1:8000/api/auth/login
Headers: Content-Type: application/json, Accept: application/json
Body JSON: {"email": "budi@padukerja.id", "password": "password123"}
Tujuan: Melakukan verifikasi kredensial akun pelamar dan menghasilkan tanda pengenal digital stateless (JWT Token) berdurasi aktif 7 hari.
Request 2 Method: PUT | URL: http://127.0.0.1:8000/api/profile/skills
Headers: Content-Type: application/json, Accept: application/json, Authorization: Bearer <Token_JWT>
Body JSON: {"skills": ["PHP", "Laravel", "MySQL", "Git", "Redis", "Docker", "REST API"]}
Tujuan: Memperbarui daftar keahlian (skills matrix) pada profil pelamar yang sedang login melalui otorisasi middleware JWT.
Request 3 Method: GET | URL: http://127.0.0.1:8000/api/auth/me
Headers: Authorization: Bearer <Token_JWT>, Accept: application/json
Tujuan: Memverifikasi bahwa token JWT valid dan memastikan data keahlian yang diperbarui pada Request 2 telah tersimpan persist di database.
(Note: Uji Negatif coba POST login dengan password salah menghasilkan 401 Unauthorized).
Status code yang ditemukan
  • 200 OK: Berhasil login, berhasil update array keahlian, dan berhasil memuat profil.
  • 401 Unauthorized: Ditemukan saat login dengan password salah atau request PUT skills tanpa menyertakan Header Authorization Bearer.
  • 422 Unprocessable Entity: Ditemukan jika format email salah atau array skills dikosongkan.
Header penting
  • Content-Type: application/json (Memberitahu server bahwa payload dikirim berformat JSON).
  • Accept: application/json (Memastikan server selalu mengembalikan response JSON).
  • Authorization: Bearer <token> (Token JWT untuk memvalidasi identitas user secara stateless tanpa session server).
Format response Menggunakan standar JSON Envelope PaduKerja:
status: Indikator keberhasilan ('success' atau 'error') | message: Pesan penjelasan human-readable
data: Objek data utama (token JWT, data user, list array skills, skills_count) | meta: Metadata timestamp (ISO 8601) dan versioning API ('1.0.0').
Temuan / error
  • Keamanan Stateless: Endpoint PUT skills terlindungi ketat oleh middleware JwtAuth; request tanpa token langsung ditolak (401 Unauthorized).
  • Validasi Input: Form Request memvalidasi keharusan format array pada field skills; jika bukan array atau kosong dikembalikan validasi 422.
  • Penanganan Sandi: Sandi terenkripsi aman menggunakan algoritma Bcrypt (cost 12), sehingga perbandingan sandi login terlindungi dari timing attack.
Hubungan dengan project Auth & Profile Service memegang peranan fondasional bagi seluruh ekosistem microservice PaduKerja:
1. Sentral Autentikasi: Token JWT yang diterbitkan pada Request 1 menjadi tiket otorisasi bagi pengguna untuk mengakses Lowongan, Lamaran, dan Pipeline.
2. Bahan Baku Matchmaking: Data array keahlian yang disimpan melalui Request 2 menjadi input krusial bagi Matchmaking Engine dalam mengkalkulasi persentase kecocokan skill pelamar dengan kualifikasi lowongan menggunakan rumus Weighted Jaccard Similarity.
Kesimpulan Pengujian REST API bagian Auth & Profile Service menggunakan Postman berhasil 100% dan memenuhi seluruh kontrak spesifikasi perkuliahan. Autentikasi berbasis JWT berjalan stateless, aman, dan responsif. Pengelolaan data profil keahlian pengguna mampu menyimpan array keahlian secara dinamis dan siap disuplai ke modul matchmaking seleksi kerja.

Analisis & Pembahasan Tujuan Pengujian: Memperbarui daftar keahlian (skills matrix) pada profil pelamar yang sedang login melalui otorisasi middleware JWT.
Hasil Analisis: Method HTTP PUT diterapkan secara presisi untuk operasi replace penuh kumpulan data keahlian. Response berstatus 200 OK mengonfirmasi jumlah keahlian aktif (skills_count: 7).
